# Stand-in site photographs

Photographs shown for shelters and safe parking lots that nobody has sent a
photo of. **None of them is any of these sites.** Every surface that shows one
says so, on the picture and in its alt text.

Sourced from Wikimedia Commons categories by `scripts/fetch-site-photos.py`,
which also documents why categories rather than search, and what is filtered
out. The generated index is `lib/listings/site-photos.ts`.

109 images, 11.9 MB, 900px wide, EXIF stripped.

A lot that has not published what it takes gets the plain car lot, never the
RV one. Null means not published, and showing a motorhome would send somebody
sleeping in one to a lot that turns them away.
